# المزامنة بين الأجهزة

بصائرنا يعمل بالكامل على الجهاز. هذا المستند لمن أراد لاحقًا أن يرى المعلّم تقدّم طلابه
مباشرة دون تبادل ملفات.

لا شيء من هذا مطلوب لتشغيل البرنامج. اتركه كما هو ما لم تحتج المزامنة فعلًا.

---

## كيف تُفعَّل

ضع عنوان الخادم في `js/config.js`:

```js
sync: {
  endpoint: 'https://api.example.com/basairuna',
  autoSyncSeconds: 60
}
```

---

## العقد المطلوب من الخادم

الخادم مستودع سجلات فحسب. لا يحتاج أن يفهم معنى أي حقل — يكفي أن يحفظ
ويعيد ما حُفظ، ويحسم التعارض بـ «الأحدث يفوز» اعتمادًا على `updatedAt`.

### `POST /push`

يرسل الجهاز ما تغيّر لديه منذ آخر مزامنة.

```jsonc
{
  "deviceId": "dev_a1b2c3",
  "since": 1769500000000,          // آخر updatedAt استلمه هذا الجهاز
  "changes": {
    "users":   [ { "id": "std_…", "name": "…", "updatedAt": 1769512345678 } ],
    "entries": [ { "id": "ent_…", "userId": "std_…", "updatedAt": 1769512345678 } ],
    "salah":   [ { "id": "std_…|2026-07-27", "slots": { "fajr": 1 }, "updatedAt": … } ]
  }
}
```

الرد:

```jsonc
{ "ok": true, "serverTime": 1769512400000 }
```

### `GET /pull?since=<ms>&deviceId=<id>`

يعيد كل سجل `updatedAt > since`، بنفس شكل `changes` أعلاه، عدا ما أرسله هذا الجهاز نفسه.

```jsonc
{
  "changes": { "entries": [ … ], "salah": [ … ] },
  "serverTime": 1769512400000
}
```

### التسجيلات الصوتية

سجلات `voice` و`tracks` تحمل حقل `blob`. لا تمرّرها في JSON.

ارفعها منفصلة إلى `POST /blob/:id` بجسم ثنائي، واستبدل الحقل في السجل بـ:

```jsonc
{ "blobUrl": "https://api.example.com/basairuna/blob/vo_123" }
```

ثم نزّلها عند الحاجة فقط — لا مع كل مزامنة. ملف تسجيل واحد قد يفوق حجمه
كل سجلات الطالب النصية مجتمعة.

## أين يُوصَل الكود

`js/storage.js` هو الطبقة الوحيدة التي تلمس التخزين، وكل قراءة أو كتابة في البرنامج
تمرّ عبر `js/models.js`. لذلك تكفي إضافة ملف `js/sync.js` يفعل ما يلي:

```js
DB.on((store, action, payload) => {
  /* ضع السجل في طابور الإرسال */
});

/* كل CONFIG.sync.autoSyncSeconds: */
async function cycle() {
  await push(queue);                 // أرسل ما تغيّر
  const remote = await pull(lastSync);
  await DB.importAll({ app: 'basairuna', stores: remote.changes }, { merge: true });
  Router.render();                   // أعد رسم الصفحة الحالية
}
```

`DB.importAll` يطبّق «الأحدث يفوز» على مستوى السجل، وهي القاعدة نفسها التي يستخدمها
الاستيراد اليدوي — فلا حاجة لمنطق دمج منفصل.

لا تنسَ إضافة `js/sync.js` إلى `index.html` وإلى قائمة `SHELL` في `sw.js`.

## بدائل أبسط

قبل بناء خادم، تحقّق أن الحاجة تستحق:

- **جهاز واحد للحلقة**: كل الحسابات عليه، والمعلّم يرى كل شيء فورًا. لا يحتاج شيئًا.
- **تصدير واستيراد**: يكفي في الحلقات الأسبوعية. الطالب يرسل ملفًا، والمعلّم يستورده.
  زر «إرسال سجلاتي للمعلّم» يفتح قائمة المشاركة في الجوال مباشرة.
- **خدمة جاهزة**: Firebase أو Supabase تعطيك نفس النتيجة دون كتابة خادم،
  وتُوصَل من نفس النقطة الموصوفة أعلاه.

---

## الخصوصية

سجلات الطلاب تخصّ قاصرين في الغالب: أسماؤهم، ومواظبتهم على الصلاة، وتسجيلات بأصواتهم.

إن نقلتَها إلى خادم فاستأذن أولياء الأمور، واجعل الاتصال عبر `https`، وقيّد الوصول
بحيث لا يرى أحدٌ إلا طلابه، ولا تحتفظ بالتسجيلات الصوتية أطول مما يلزم.
